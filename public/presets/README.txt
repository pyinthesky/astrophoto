ASTRO NPF · NIGHT SKY — LIGHTROOM PRESET PACK

Six gentle starting points for casual astrophotography:

01 Clean Natural          Balanced contrast and detail
02 Milky Way Pop          Stronger core separation and color
03 Light Pollution Cut    Reduces common orange/yellow sky glow
04 Warm Galactic Core     Warm core with subtly cool shadows
05 Star Trails            Crisp, bright trails and deeper blacks
06 Nightscape Balance     Opens a foreground without flattening the sky

These presets adjust contrast, highlights, shadows, whites, blacks, texture,
clarity, dehaze, color, sharpening, noise reduction, and chromatic aberration.

They DO NOT set exposure, white balance, crop, transform, lens profile, or AI
masks. Set exposure and white balance for each photograph after applying a
preset. Reduce dehaze or sharpening if halos or crunchy stars appear.

INSTALL

Lightroom desktop:
File > Import Profiles & Presets, then select the ZIP.

Lightroom Classic:
Develop > Presets panel > + > Import Presets, then select the ZIP.

Lightroom mobile:
Unzip this pack. Open Presets > Yours > Options > Import Presets, then select
the individual XMP files.

Designed for RAW photographs. Lightroom / Camera Raw compatibility may vary by
app version. These files are plain XMP development presets and contain no code.
